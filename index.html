01 About

Gameplay systems, and the tools behind them.

I'm a game developer from Hungary, based in Budapest, with a BSc in Computer Science and more than ten years of software engineering behind me. I started in enterprise software, spending five years as a .NET developer at Siemens (evosoft), then moved into games at Gameloft, where I worked in Unity on Rob and Renovate.

After that I spent four years working remotely for Fortis Games, a US-based studio, on Bloom & Breakfast.

My main areas are gameplay programming and in-engine tooling: the systems players touch, and the editor tools that let designers and artists work without waiting on a programmer. When a project needs it, I'm comfortable on the server and backend side too.

Outside of work I'm always building something. Right now that's Springdale, a solo first-person thriller in pre-alpha, alongside a few smaller games and tools.

03 Featured project

Springdale

Pre-alphaSolo project · Working title

Springdale is my current solo project, now in pre-alpha: a first-person mystery thriller set in an alternate early-1990s America. An engineer goes looking for his wife in a small mountain town that has quietly closed its roads to outsiders, and where everyone enforcing the closure seems to think that is perfectly normal.

You play a capable engineer, not a soldier. The loop is explore, investigate, understand, improvise, overcome: problems are solved with ingenuity before force, and the mood is carried by place, lighting and sound.

  • Unity 6
  • HDRP
  • C#
  • Timeline
  • Blender
  • Python

Built so far

  • Full-body first-person character with traversal, held items and a flashlight
  • NPC behaviour architecture: routines, perception, stealth, guards and restricted areas
  • Story progression, dialogue, Timeline cutscenes and tutorials
  • Inventory, interaction, locks, readables and maps
  • Time of day, weather and lighting driven by the story
  • Saving, checkpoints and covered scene loading
  • A MetaHuman to Unity character pipeline and custom editor tooling

Pre-alpha. Everything shown here is work in progress. Systems, art and lighting are still changing, and none of it represents the final game.

Editor tooling

Traversal Library is one of the editor tools I built for the project. Mark a ledge or a gap in the Scene view and it infers the move (climb, drop, jump or vault), fits the animation to the geometry, and checks clearance for the player and NPCs along the whole usable width. Nothing touches the level until the draft is confirmed.

Floor Fighters

A slapstick physics party brawler for PC. Wobbly active-ragdoll fighters rip tiles out of the arena floor and throw them at each other: every throw costs you footing, and a miss arms your opponent. Proven first as a browser prototype, now being built in Unity.

  • Unity 6
  • URP
  • Physics

In developmentPrivate

EscaPals

Co-operative escape rooms for phones. One to six friends each play on their own device, with one device hosting authoritatively. The rules live in a pure C# package tested without Unity, and rooms are plain data authored in a custom room editor. It began as a browser prototype with a server-authoritative TypeScript engine before moving to Unity.

  • Unity 6
  • UI Toolkit
  • Netcode
  • NUnit

Tools & pipelines

Open source

Live Game Data Editor

A Unity Editor extension for editing ScriptableObject-backed game data in a spreadsheet-style table: typed rows, validation, Undo/Redo, multi-row editing, JSON and CSV import/export, and Google Sheets sync. Built with UI Toolkit, with runtime and editor assemblies kept apart so builds stay clean.

  • Unity 2022.3+
  • UI Toolkit
  • Editor tooling
  • C#
View on GitHub
In usePrivate

MetaHuman to Unity pipeline

Brings MetaHuman Creator characters into Unity HDRP in one click. Unreal export and bake scripts, a Blender converter that merges meshes, simplifies the skeleton and builds LODs, and a Unity importer that produces Humanoid prefabs with skin, eye and hair materials. Built for Springdale.

  • Python
  • Blender

  • Unity HDRP
